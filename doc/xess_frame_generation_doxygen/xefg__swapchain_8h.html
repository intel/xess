◆ XEFG_SWAPCHAIN_USE_MAX_SUPPORTED_INTERPOLATED_FRAMES

#define XEFG_SWAPCHAIN_USE_MAX_SUPPORTED_INTERPOLATED_FRAMES   UINT32_MAX

Use maximum supported number of interpolated frames.

Use this constant during XeSS-FG swap chain initialization to set number of interpolated frames to the maximum supported value.

The actual value can be queried later using xefgSwapChainGetProperties or by retrieving back the initialization parameters.

See also
XeSS-FG Swap Chain D3D12 API exports

enum _xefg_swapchain_ui_mode_t

XeSS-FG UI composition mode.

XeSS-FG can either interpolate UI (default) or compose a UI texture as-is on top of the interpolated frames. The application can provide the UI texture directly or rely on XeSS-FG to extract the texture from other available resources.

UI composition can be enabled or disabled by changing the composition state. When UI composition is enabled, the UI mode determines which composition method is used.

See also
xefgSwapChainSetUiCompositionState for enabling or disabling UI composition.
Enumerator
XEFG_SWAPCHAIN_UI_MODE_AUTO 

Determine UI composition mode automatically, based on provided inputs: hudless color and UI texture.

XEFG_SWAPCHAIN_UI_MODE_NONE 

Interpolate back buffer, without any UI composition.

XEFG_SWAPCHAIN_UI_MODE_BACKBUFFER_UITEXTURE 

Interpolate back buffer, refine UI using UI texture + alpha.

XEFG_SWAPCHAIN_UI_MODE_HUDLESS_UITEXTURE 

Interpolate hudless color, blend UI from UI texture + alpha.

XEFG_SWAPCHAIN_UI_MODE_BACKBUFFER_HUDLESS 

Interpolate hudless color, extract UI from backbuffer.

XEFG_SWAPCHAIN_UI_MODE_BACKBUFFER_HUDLESS_UITEXTURE 

Interpolate hudless color, blend UI from UI texture + alpha and refine it by extracting from back buffer.
